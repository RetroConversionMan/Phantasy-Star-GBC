# Assembly and source index

The native port is mainly C. This index maps each of the 262 production C units to its generated SM83 assembly, assembly listing, object, and symbols. The original Z80 disassembly is excluded from this revised package. The linker map and NOI file in `current-project/build/` give final bank/address placement.

Authored inline SM83 assembly lives in:

- [palette_commit.c](current-project/src/palette_commit.c)
- [dungeon_motion_upload.c](current-project/src/dungeon_motion_upload.c)
- [ending_upload.c](current-project/src/ending_upload.c)

Machine-readable file hashes: [ASSEMBLY_INDEX.json](ASSEMBLY_INDEX.json).
